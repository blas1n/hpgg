# 기획: 디스코드 연동 파티 구인 (게임 음성 채팅 공백 대응)

작성 2026-10-28 · 상태: **초안 — 오너 검토 전, 착수 안 함** · 관련 이슈: #7 커뮤니티, #28 Battle.net 로그인

## 배경

게임 음성 채팅이 고장으로 꺼져 있다(오너 전언, 직접 확인은 안 함). 그 빈자리를 hpgg 커뮤니티 기능과 디스코드로 가져갈 수 있는지 검토한다.

## 하지 않는 것: 게임 음성 채팅 대체

"그 판의 모르는 팀원 4명과 바로 대화"는 만들 수 없다.

- 같은 팀이 누군지 알려면 로딩 중 로비 파일을 읽는 데스크톱 앱이 필요하다. 이 방향은 10-07에 포기했다(ROADMAP 보류/포기: 공식 API 없음, 약관 위험).
- 앱이 있어도 팀원 전원이 앱 설치와 디스코드 연동을 해 둬야 쓸 수 있다. 지금 규모에서는 같은 판에 걸릴 일이 사실상 없다.
- 밴픽 1~2분 안에 모르는 사람이 디스코드 서버에 들어와 음성방에 접속하는 흐름은 성립하지 않는다.

## 하는 것: "같이 할 사람 찾기 + 음성 연결"을 한 번에

음성이 실제로 필요한 경기는 파티 경기다(파티 빠대, 영웅리그 듀오/트리오, 5인 파티). 게임 음성이 꺼진 지금은 사람을 구하는 일과 음성을 연결하는 일을 각자 따로 해결하고 있다. 이 두 가지를 이어 준다.

### 1단계 — 디스코드 서버와 봇 (사이트 변경 거의 없음)

| 기능 | 내용 |
|---|---|
| 개인 음성방 자동 생성 | "➕ 방 만들기" 대기실에 들어오면 그 사람의 음성방을 만들어 옮겨 주고, 비면 삭제 |
| 구인 채널 | 모드·티어·인원·원하는 역할을 고르는 양식(슬래시 명령 또는 버튼). 글에 그 사람의 음성방 링크를 붙임 |
| `/전적 배틀태그#1234` | 사이트 전적 API(`/v1/players`)를 그대로 써서 요약 카드와 사이트 링크를 보여 줌 |
| 주간 리포트 공지 | 월요일 리포트 PR이 머지되면 공지 채널에 링크 게시 |

- 봇은 Mac mini에 컨테이너 하나를 추가한다(hpgg-api 옆). 사이트 API만 호출하므로 HP 호출량은 사이트 검색과 같은 캐시·한도를 공유한다.
- 사이트 헤더나 푸터에 디스코드 초대 링크 하나만 추가한다.

### 2단계 — 사이트 파티 구인판 (1단계 반응이 기준을 넘으면)

- 구인글에 작성자의 티어, 주력 영웅 3개, 최근 20판 승률을 자동으로 붙인다. 손으로 쓰는 구인글과 갈리는 지점은 우리 전적 데이터다.
- 글은 디스코드 구인 채널과 양방향으로 연결하고, "참가"를 누르면 디스코드 음성방으로 보낸다.
- 신원은 지금 댓글과 같은 닉네임+태그(ip HMAC) 방식으로 시작한다. 자동으로 붙는 티어는 **"배틀태그 기준 조회값"으로 표기**하고 본인 인증은 아니라고 밝힌다.

### 3단계 — Battle.net 로그인(#28)

- 로그인한 배틀태그로 쓴 글에 "인증됨"을 표시한다. 디스코드 계정과 연결하면 봇이 티어 역할을 자동으로 준다.
- 필요한 것: 오너의 Battle.net 개발자 클라이언트 ID/시크릿.

## 지켜야 할 것

- **HP 약관 §3:** 봇은 한 명씩 조회만 한다. 데이터셋 덤프, 일괄 조회, 내보내기 명령은 만들지 않는다.
- **비공개 플레이어:** 사이트가 숨기는 선수(`hp_private_player`)는 봇에서도 숨긴다. 봇이 사이트 API만 쓰면 자동으로 지켜진다.
- **모더레이션:** 신고 3회 숨김 규칙을 구인판에도 적용한다. 디스코드는 기본 AutoMod와 관리자 역할로 운영한다. 오너 혼자 운영하는 부담을 늘리지 않는 쪽으로 설계한다.

## 착수 조건 (현재 트래픽, 2026-10-28 측정)

GoatCounter 대시보드는 로그인이 필요해서 이번 측정에서는 서버 쪽 숫자만 봤다. 방문자 수는 오너가 대시보드에서 확인해야 한다.

| 지표 | 값 | 출처 |
|---|---|---|
| 전적 검색 (HP 실호출, 캐시 미스) | 10월 초 20~40/일 → 10-12~16 고점 41~59/일 → 10-17 이후 11~33/일 | `hp_daily_usage` players |
| 댓글 스레드 조회 (영웅·리포트 페이지 열람 근사치) | 13시간에 106회 → 하루 약 200 | API 로그 `GET /v1/comments` |
| 누적 댓글 | **1개** (`hero:zagara`) | `comments` |

- 검색 수는 캐시 미스만 센 값이고 오너 본인 사용분도 섞여 있다. 그래서 실제 검색 수는 이보다 많고, 서로 다른 사람 수는 이보다 적을 수 있다.
- 해석: 하루 순방문은 많아야 수십 명 수준으로 보인다. 댓글이 1개라는 건 지금 방문자가 **사이트 안에서 서로 대화하지 않는다**는 뜻이다. 2단계(사이트 구인판)를 지금 열면 빈 게시판이 된다.

**제안 기준:**

- 1단계는 비용이 작으니 지금 해도 된다. 다만 "아카 홍보 글 → 디스코드 유입"이 실제로 일어나는지 보는 실험으로 다룬다.
- 2단계는 디스코드 서버 **멤버 100명 이상**, 그리고 구인 채널 글이 **주 10개 이상**인 상태가 2주 이어지면 착수한다.
- 4주 안에 멤버 30명 미만이면 접고 공지 채널로만 남긴다.

## 열린 질문 (오너)

1. 게임 음성 채팅이 꺼진 범위: 전체인지, 일부 모드·지역만인지. 복구 예정이 있다면 1단계의 가치가 줄어든다.
2. 디스코드 서버를 hpgg 이름으로 새로 열지, 기존 히오스 한국 디스코드와 제휴할지. 기존 서버에 봇만 넣는 쪽이 초기 사람 문제를 피할 수 있다.
3. GoatCounter 주간 방문자와 재방문 수치 공유(또는 API 토큰을 `deploy/.env`에 넣어 주간 지표 자동 수집).
