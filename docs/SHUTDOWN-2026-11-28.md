   1. 브랜치: `main` 외 전부 삭제 (`snapshots` 는 공개 데이터셋, `data/*` 포함 약 200개).
   2. 이력 정리 — 새 mirror clone에서 (합성 픽스처 PR이 main에 들어간 뒤):
      ```bash
      git clone --mirror git@github.com:blas1n/hpgg.git hpgg-purge.git && cd hpgg-purge.git
      git for-each-ref --format='%(refname)' refs/heads | grep -v '^refs/heads/main$' | xargs -n1 git update-ref -d
      # (a) 경로째: HP 데이터 하위 경로 + 다른 사이트 캡처 (목록과 이유는 파일 머리말)
      git filter-repo --invert-paths --paths-from-file <worktree>/docs/shutdown/purge-paths.txt
      # (b) 픽스처는 경로는 두고 옛 내용만: 이 디렉터리들의 blob 중 HEAD에 없는 것 전부
      D='tests/fixtures tests/server/fixtures web/tests/fixtures web/tests/e2e-data'
      git rev-list --objects --all -- $D | awk 'NF==2{print $1}' | sort -u > all.txt
      git ls-tree -r HEAD | awk '{print $3}' | sort -u > head.txt   # 트리 전체: 같은 내용이 다른 경로에 살아 있으면 지우면 안 됨
      comm -23 all.txt head.txt | git cat-file --batch-check='%(objectname) %(objecttype)' | awk '$2=="blob"{print $1}' > strip.txt
      git filter-repo --strip-blobs-with-ids strip.txt --force
      ```
      `data/` 게임 정보(영웅·전장 이름표, 특성, 패치노트, 핫픽스, 이미지)는 HP 데이터가 아니고 테스트가 읽으므로
      남긴다. 빈 `data:` 일일 커밋은 filter-repo가 제거.
      같은 커밋에서(이력 정리 직후 main에 새 커밋): `web/scripts/sync-data.mjs` 기본 DATA_DIR을
      `tests/e2e-data`로, `.github/workflows/collect-and-deploy.yml`·`tools/collect/` 삭제, `ci.yml`에서 Pages 관련
      없음 확인.
   3. 검증: `grep -v '^#' purge-paths.txt | xargs git log --all --oneline --` 비어 있음, `strip.txt`의 아무 id나
      `git cat-file -e` 실패, 클론해서 `uv run pytest`·`npm test`·`npm run e2e` 통과.
